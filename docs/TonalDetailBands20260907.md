# Detailed tonal measurement bands

The existing four tonal percentages remain the public compatibility layer used by the current assessment model:

- Low: 20–250 Hz
- Low-mid: 250 Hz–2 kHz
- High-mid: 2–8 kHz
- High: 8–20 kHz

For future tonal-balance calibration, the analyzer also measures eight non-overlapping detailed bands whose pairs sum back into the four legacy bands:

1. Sub: 20–80 Hz
2. Bass: 80–250 Hz
3. Low-mid body: 250–500 Hz
4. Mid: 500 Hz–2 kHz
5. Presence: 2–5 kHz
6. Upper presence: 5–8 kHz
7. Brilliance: 8–12 kHz
8. Air: 12–20 kHz

This change is measurement-only. The detailed bands do not affect technical, style, master-quality, streaming, or overall verdicts until separately calibrated and regression-tested.
